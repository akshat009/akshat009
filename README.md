## About

I build custom WordPress themes, plugins, and Gutenberg blocks — across enterprise environments (via Capgemini) and US digital agency client work. I also publish plugins independently on the WordPress.org repository.

Most recent: **[Multimage – Image Uploads for WPForms](https://wordpress.org/plugins/multimage-image-uploads-for-wpforms/)** — adds a multi-image upload field to WPForms, including the free Lite tier, which ships no file upload field natively. Token-based AJAX pre-upload flow, server-side MIME validation, full PHPUnit test suite.
